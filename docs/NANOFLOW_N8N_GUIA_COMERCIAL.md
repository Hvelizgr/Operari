## Funcionalidades Técnicas de NanoFlow + n8n

### API REST Implementada

```typescript
// Endpoints disponibles en n8nService

// Health & Status
healthCheck()                    // Verificar conexión con n8n

// Workflows
getWorkflows()                   // Listar todos los workflows
getWorkflow(id)                  // Obtener workflow específico
createWorkflow(name, nodes)      // Crear nuevo workflow
updateWorkflow(id, data)         // Actualizar workflow
deleteWorkflow(id)               // Eliminar workflow
activateWorkflow(id)             // Activar workflow
deactivateWorkflow(id)           // Desactivar workflow

// Ejecuciones
executeWorkflow(id, data)        // Ejecutar por ID
executeWorkflowData(workflow)    // Ejecutar sin guardar
getExecution(id)                 // Obtener resultado
getExecutions(workflowId, limit) // Listar ejecuciones
deleteExecution(id)              // Eliminar ejecución

// Nodos
executeN8nNode(node, input)      // Ejecutar nodo individual
isN8nNode(type)                  // Verificar si es nodo n8n
getAvailableNodeTypes()          // Listar tipos disponibles
```

### Tipos de Nodos Soportados

| Tipo | Descripción | Uso Común |
|------|-------------|----------|
| `n8n-http` | Peticiones HTTP | APIs externas |
| `n8n-code` | Código JavaScript | Lógica personalizada |
| `n8n-function` | Funciones | Transformación de datos |
| `n8n-set` | Establecer valores | Configurar variables |
| `n8n-if` | Condicional | Bifurcación de flujo |
| `n8n-switch` | Switch múltiple | Rutas múltiples |
| `n8n-merge` | Combinar datos | Unir flujos |
| `n8n-split` | Dividir datos | Separar flujos |

## Configuración Técnica

### Variables de Entorno

```bash
# Conexión con n8n
N8N_BASE_URL=http://localhost:5678
N8N_API_KEY=tu-api-key-opcional

# Límites para versión gratis
NANOFLOW_MAX_WORKFLOWS=3
NANOFLOW_MAX_NODES=10
NANOFLOW_MAX_EXECUTIONS_DAY=50
NANOFLOW_DATA_RETENTION_HOURS=24
```

### Requisitos del Sistema

#### Para Demo/Pruebas (tu servidor)
- Node.js 18+
- n8n instalado y corriendo
- 2GB RAM mínimo
- 10GB almacenamiento

#### Para Clientes (instalación)
- Node.js 18+ o Docker
- 2GB RAM (básico) / 8GB RAM (producción)
- PostgreSQL (recomendado para producción)
- SSL/HTTPS para producción
